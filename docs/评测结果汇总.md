## 四、分层与可靠性

- **分层 mAP50**：IP102 害虫子集 **0.932**（1114 图）/ 全量 0.648 / PlantDoc 病害子集 **0.492**（210 图）
  （PicoDet 对照：0.905 / 0.459，两极同步提升）
- **置信度校准**：ECE(10bin) = **0.0546**、MCE = 0.198（N = 235,889 候选框）；0.95 置信箱实际命中率 0.975
- **逐框精确率/召回**：
  - @0.80：全量 0.958 / 害虫 0.994 / 病害 0.803（recall 0.33——softmax 头分数保守，高置信即高可靠）
  - @0.35：全量 0.678 / 害虫 0.852 / 病害 0.398（recall 0.832——演示默认阈值，查全优先）
  - @0.20：0.389 / recall 0.905；@0.50：0.840 / recall 0.744
- **逐类 F1 最优阈值**：病害 0.31~0.59、虫害 0.36~0.45（跨类差异明显，业务可按需分类别设阈值）

## 五、误报特性

- **健康叶图**（val 中仅含 tomato_leaf_healthy 真值的 13 张）：非健康检出 **0.5 个/图 @0.35**（PicoDet 为 1.8 个/图，大幅改善）
- **非目标类负样本**（21 张 / 20 类，模型未见过的类别）：0.35 档检出 38 个 = 1.73 个/图；逐框 IoU≥0.5 匹配后 **63% 为跨类命中**（框到真目标但类别错，如苹果黑星病→番茄叶霉）、37% 纯虚警（近半在纯背景田间照）
- 失效模式结构与前代（62%/38%）一致：**主要错误是跨物种类别混淆，而非凭空虚警**

## 七、杂草引擎（PP-PicoDet-L-640，CottonWeedDet12）

> 口径：导出部署链路（与病虫引擎同款 Detector）、阈值 0.35、COCOeval；
> 数据双口径划分（随机种子 0 / 分层），训练集弱类过采样后 200 epoch 早停 @110（Best val mAP50 0.845）。

- 随机划分逐类 AP50：镰荚决明 1.000、裂叶酸浆 1.000、牵牛花 0.979、豚草 0.977、牛筋草 0.970、
  长芒苋 0.968、鳢肠 0.968、长序苋 0.960、斑地锦 0.960、刺黄花稔 0.941、马齿苋 0.936、粟米草 0.915
- **INT8 量化（PTQ）：不采用**——两轮不同校准集 mAP50 均从 0.9646 崩至 0.209 / 0.266（框系统性膨胀为近全图 + 类别大面积混淆），
