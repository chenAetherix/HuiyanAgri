### 💬 农事问答聊天页（v4 新增，主界面按钮进入；已内置 key）

| 测试点 | 预期 |
|---|---|
| 进入 | 欢迎语气泡（左白底）；输入框+发送按钮 |
| **真机**发问（需手机联网） | 正常回答农事问题；用户消息右侧绿底气泡、回复左侧白底气泡 |
| 检测联动 | 主页完成任一次检测后进聊天页问"这个怎么治"——回答针对最近检出类别 |
| **模拟器**发问 | **模拟器无外网（DNS 全断），必回"⚠️ 问答服务暂时不可用（UnknownHostException）"——这是正确降级不是 bug**；真机联网即正常 |
| 返回键 | 软键盘先收起、再按返回主页（注意模拟器连续按两次会退到桌面，重进即可） |

### 模拟器 vs 真机

- 模拟器单帧推理 **2~6 分钟**（随图大小浮动；x86 翻译层逐指令模拟 arm，正常现象）
- 综合模式 ≈ 两单模式耗时之和
- 真机 ARM 原生预计 0.1~0.5 秒/帧、综合约 2 秒（**均为预估，未实测**）

## 六、"看着像 bug 其实是设计"判定清单

| 现象 | 判定 |
|---|---|
| 杂草图在病虫 Tab"未检出"或仅低置信"健康" | ✅ 正确（双专家架构：跨域引擎保持沉默） |
| 病虫图在杂草 Tab 无结果 | ✅ 正确（同上） |
| 阈值调低后检出数没变 | ✅ 可能（该图无边界候选；换图验证） |
| 安卓综合模式卡片不按引擎分列 | ✅ 设计差异（网站分列、安卓合并） |
| 模拟器推理几分钟 | ✅ 翻译层固有（真机不会） |
| 119B 图检出"晚疫"而非文件名暗示的"叶霉" | ✅ 已知近缘混淆（模型判晚疫 75%，材料有近缘混淆分析） |
| 网站与安卓同图分数差 ±0.01 | ✅ 浮点舍入显示 |
| 问答提示"尚未配置智谱 API key" | ✅ 正常降级（用了未带 key 构建的 APK；重打包时构建命令前 set ZHIPU_API_KEY 即可） |
| 问答回复"服务暂时不可用（UnknownHostException）" | ✅ 当前设备无外网（模拟器 DNS 全断即此表现）；联网后自动恢复，检测功能不受影响 |
| 关网后三个检测 Tab 照常工作 | ✅ 正确（检测全程离线；只有问答需联网） |
